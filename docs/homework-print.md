# 宿題プリントの作り方（手順書）

授業で扱った回の文法事項を、宿題として復習させるプリントです。1回分を作るときの仕様と手順をまとめます。

形式は2種類あります。

| 形式 | 対象 | 中身 |
|---|---|---|
| 文法型（`"layout": "grammar"`、省略時もこれ） | 準1級・2級・準2級プラス・準2級 | 大問1形式の4択10〜14問。★は全訳 |
| 書き写し型（`"layout": "writing"`） | 3級・4級・5級（小中学生向け） | 単語練習と例文の書き写し（英語4線）、大問1形式の4択6〜8問（★は4線に書き写し）、つづり確認 |

## 1. 仕様

| 項目 | 内容 |
|---|---|
| 用紙 | A4縦・4ページ固定（1〜2ページ目が問題、3〜4ページ目が解答・解説） |
| 問題 | 授業の文法事項（`lessonPlan.focusPoints` の fp1〜fp4）を問う、大問1形式の4択。10〜14問 |
| 全訳 | ★の付いた3〜5問は、完成した英文を全訳する（1ページ目・2ページ目に3行の記入欄） |
| 解説 | 各問に「正解／訳／解説／選択肢（各選択肢の意味）／講師のひとこと」。最後に「講師から生徒へのひとこと」 |
| 次回の案内 | 4ページ目の最後に、次回の授業日と、次回扱う回の単語フラッシュカードのQR（`vocab-cards.html?data=…`） |
| 印刷場所 | トップの「🖨️ 授業プリント作成」（print.html）→ 級と回を選ぶ →「過去問・講師用資料・宿題プリント」→ 宿題プリント［作成］ |
| デザイン | 講師用解答解説（eiken-pre2-session-09-teacher）の形式に準拠。紺の見出し、赤字の正解、青枠の「講師のひとこと」、クリーム色の締めくくり枠、柱とページ番号 |

作成時のモーダルでは、次回の授業日（カレンダー）、次回の級、次回の回（実装済みの回をラジオボタンで新しい順に表示）を選びます。初期値は「1週間後・同じ級・ひとつ前の回」です。「次回の案内とQRコードを入れない」も選べます。

問題・解説は高さを測りながらページに流し込みます（1ページ目に入らない分は2ページ目へ、3ページ目に入らない分は4ページ目へ）。ページの最後に「Part ○」の見出しだけが残る場合は、見出しも次のページへ送ります。問題ページ・解説ページのどちらかが収まらないときは、そのページだけ文字と余白を詰めて組み直します（2段階まで）。それでも収まらなければプレビューに赤枠が出ます。

## 2. データの置き場所と形式

- 1回分のデータ：`data/homework/<級のフォルダ>/<回>.json`（例：`data/homework/grade2/2026-2-sat.json`）
- 一覧：`data/homework/index.json`（`scripts/build_homework.py` が自動で作る。手で編集しない）
- 見本：`data/homework/pre-grade1/2026-2.json`

| キー | 内容 | 目安 |
|---|---|---|
| `grade` / `exam` | ファイルの場所と同じ級・回 | — |
| `title` | 宿題の題名（例：文法事項の確認） | 2〜20字 |
| `theme` | 柱の右側に出るテーマ | 4〜30字 |
| `aim` | この宿題のねらい | 40〜140字 |
| `goals` | 到達目標（□付きで表示） | 3〜4項目、各8〜40字 |
| `instruction` | 問題の指示文。「(1)から(N)まで」と「★の問題は…全訳しなさい」を含める | — |
| `questions[]` | 下表 | 10〜14問 |
| `closing` | 講師から生徒へのひとこと | 80〜200字 |

`questions[]` の各問：

| キー | 内容 | 目安 |
|---|---|---|
| `number` | 1から連番 | — |
| `focus` | その回の学習ポイントID（fp1〜fp4） | 3つ以上のポイントを使う |
| `text` | 英文。空所は全角スペース入りの `(　)` を1つ | 120字以内 |
| `choices` | 選択肢4つ（重複なし） | — |
| `answer` | 正解の番号（1〜4） | 1〜4がそれぞれ2回以上、偏らせない |
| `translate` | ★（全訳問題）なら `true` | 3〜5問 |
| `translation` | 正解を入れた英文の訳（★以外にも必ず書く。解説の「訳」になる） | 15〜60字 |
| `explanation` | 解説 | 30〜110字 |
| `choiceNotes` | 各選択肢の意味・働き。`choices` と同じ順で、各要素は選択肢の語で始める（例：`that「～という（同格）」`） | 合計70字以内 |
| `tip` | 講師のひとこと（そのまま声に出して伝えられる長さ） | 15〜70字 |

### 書き写し型（3級以下）の追加・変更点

見本：`data/homework/grade3/2026-2.json`

| キー | 内容 | 目安 |
|---|---|---|
| `layout` | `"writing"` | — |
| `words` | Part 1・Part 4 で使う単語 `{word, meaning}`。`word` はその回の `vocabulary` の見出し語と完全に同じつづり | 5〜7語（標準6語）、各14文字以内、意味は12字以内 |
| `sentences` | Part 2 で書き写す例文 `{en, ja, focus, point, note}`。`en` は授業で読んだ文をそのまま（話者名は付けない） | 2〜3文（標準3文）、25〜60字程度 |
| `questions` | 6〜8問（標準8問）。★は `"copy": true`（`translate` は使わない） | ★は2〜4問（標準3問）。★は会話文にせず1文・60字以内 |
| `instruction` | 「★の問題は，完成した英文を4線に書き写しなさい。」を含める | — |

ページの構成：
- 1〜2ページ目：Part 1 単語を書こう（うすい字をなぞって、4線に2回）、Part 2 例文を書き写そう、Part 3 問題（★は4線）、Part 3 解答欄、Part 4 日本語を見て英語を書こう（Part 1 の単語、最初の文字がヒント）
- 3〜4ページ目：Part 3 の解答・解説（文法型と同じ粒度で、文字は大きめ）、Part 4 の答え、Part 2 例文のポイント、締めくくりと次回のQR

日本語は学年に合わせる。3級は中学生向けのやさしい日本語、4級は漢字少なめ、5級はひらがな中心（カタカナと英語は可）。

## 3. 作問の方針

1. **授業の文法事項から出す。** その回の `lessonPlan.focusPoints` の fp1〜fp4（文法・構文）を読み、各ポイントから2〜4問を作る。fp5（パラフレーズ）は文法問題にしにくいので使わない。
2. **英文は新しく作る。** 過去問の文を使わない。同じ級の全回の問題文・本文・設問と一致度0.75以上の文は、検証スクリプトがエラーにする。
3. **正答は一つだけにする。** 誤りの選択肢を1つずつ空所に入れて、文法的にも意味的にも成り立たないことを確かめる。成り立つ可能性のある語（例：Without＋-ing、To＋原形の主語）は選択肢に入れない。
4. **級に合った語彙と文の長さにする。** 準1級は1〜2行の長めの文、準2級・準2級プラスは1行程度の文。
5. **★は「訳し方」が問われる問題に付ける。** 同格の「～という」、It took … before の「～するまでに」、挿入のある関係詞節など、構文の意味が日本語に表れる問題を選ぶ。
6. **解説の粒度は見本と同じにする。** 解説は「なぜその答えか」を1〜2文で。選択肢の意味は短く。講師のひとことは、授業の英文（`examples` や `sourceQuote`）と結びつける。
7. **言い切りすぎない。** 生徒がすぐ反例を思いつく一般化（「at は時間帯に使わない」など）は避ける。文法用語を正確に使う（whether は疑問詞ではなく接続詞、など）。
8. **文章は誠実で落ち着いた日本語にする**（AGENTS.md の文章トーンに従う）。根拠のない断定や煽りは書かない。
9. **問題番号への言及**（「(2)と並べて見比べる」など）は、番号を入れ替えたら必ず直す。
10. **ほかの問題の英文で答えが分からないようにする。** 同じ形を続けて出すときは、前後の問題の英文に別の問題の正解がそのまま見えていないかを確かめる。
11. **解説ページがいちばん窮屈。** 文法型は解説90字・講師のひとこと60字程度を目安にすると、詰め版にならずに収まりやすい。
12. **テーマ・ねらい・目標・練習する単語に答えの語を書かない。** `theme`・`aim`・`goals`（書き写し型は `words` も）は問題と同じページに印刷される。どの問題の正解の語句も書かず（「When と Where の使い分け」「as many と as much」も不可）、「疑問詞の使い分け」「数えられる名詞と数えられない名詞」のように、学習項目を日本語で表す。検証スクリプトもこれを確かめる。

## 4. 作成手順

1. 対象の回の `data/<級>/<回>/data.json` を開き、`lessonPlan.focusPoints` の fp1〜fp4（`title`・`explanation`・`examples`）を確認する。
2. 見本（文法型は `data/homework/pre-grade1/2026-2.json`、書き写し型は `data/homework/grade3/2026-2.json`）と同じ形式で、`data/homework/<級>/<回>.json` を作る。正解の位置は1〜4に散らす。
3. 検証して一覧を更新する。
   ```bash
   python -I scripts/build_homework.py
   ```
4. ローカルで表示と収まりを確認する（全セットについて、4ページに収まるか・はみ出しがないかを確かめる）。
   ```bash
   NODE_PATH="C:\Users\user\AppData\Local\npm-cache\_npx\e41f203b7505f1fb\node_modules" node scripts/test_homework.cjs http://127.0.0.1:8085
   ```
   印刷ページで実際に［作成］→「作成する」を押し、プレビューも目で確認する。
   級ごとに確かめるときは、環境変数 `HW_ONLY` にキーの先頭（例：`HW_ONLY=grade3/2025-2`）を付けると、その回だけを調べる（最初の見本セットの詳しい確認は毎回行う）。
5. 内容をレビューする。作った人とは別の目（サブエージェントなど）で、次を確かめる。
   - 正答が一つに決まるか（誤りの選択肢を1つずつ入れて確認）
   - 英文・訳・解説・選択肢の意味・講師のひとことが正確か
   - 問題番号への言及が正しいか
6. 指摘を反映したら、もう一度 3・4 を実行する。
7. コミットしてプッシュし、Vercelの反映後に本番サイト（https://read-pass-pro.vercel.app/print.html）で同じテストを実行する。
   ```bash
   NODE_PATH="…" node scripts/test_homework.cjs https://read-pass-pro.vercel.app
   ```

## 5. よくある調整

- **4ページに収まらない**：問題数を減らす、解説・講師のひとことを短くする、`choiceNotes` を短くする。プレビューの赤枠と、テストの「all items flowed within four pages」で分かる。
- **2ページ目・4ページ目が空きすぎる**：問題数を増やす（上限14問）か、★を増やす。
- **解答欄**：問題数に合わせて自動で折り返す。
- **過去問と似ていると判定された**：英文の場面と語彙を変えて作り直す。
